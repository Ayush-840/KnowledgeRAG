# Screenshots

This directory holds demo screenshots for the README. To add or update:

1. **Record a GIF** of the full flow: upload a doc → ask a question → see cited answer → open source drawer → open document viewer. Use [OBS](https://obsproject.com/) or [recordit](https://github.com/nicedoc/recordit) at 1440px viewport width.

2. **Take a static screenshot** of the Vector Space Explorer (3D UMAP view) — this is the most visually distinctive feature.

3. Save as:
   - `chat-citations.png` — Chat view with citation-grounded answer
   - `source-drawer.png` — Source drawer showing dense/BM25/RRF/rerank scores
   - `vector-space.png` — 3D vector space explorer with query projection

4. Keep images under 1MB each. Use PNG for screenshots, GIF for recordings.
